# BatchGuardianAI

https://triples-pm.github.io/BatchGuardianAI/

Interactive concept prototype exploring AI-native visual quality inspection in biopharmaceutical manufacturing, using simulated inspection data and workflows.

BatchGuardian AI is a computer vision project designed to support quality control in biopharmaceutical manufacturing, focusing on sterile fill-finish and labeling, serialization, and packaging.

The proposed system analyzes production-line images to detect visible defects, including vial cracks, foreign particles, closure errors, and label discrepancies. It connects detection with prioritized alerts, visual explanations, operator review, searchable inspection records, and configurable batch reports.

The project includes a four-layer architecture covering image capture, back-end processing, AI models, and operational dashboards. Its goal is to improve inspection consistency, support faster quality decisions, and automate documentation while maintaining traceability for quality assurance teams.
